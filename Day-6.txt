rm (Remove)	 [  File / Dir  ]
	
	-i intractive 

			rm -i  tg-training.txt

	-f forcefully
	
			 rm -f my*

	-r recursive  (Dir and its contents)
		
			 rm -rf  *


mv (move + Rename)	[  File / Dir  ]
   	
	File / dir source and Destination location is same  RENAME 

		Ex:  mv /root/tg-training.txt   /root/newtrg.txt



	File / dir source and Destination location is Differnt  MOVE
